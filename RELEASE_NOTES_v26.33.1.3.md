# MAX Mod v26.33.1.3 — Release Notes

**Дата:** 2026-10-01

## Что нового

Третий выпуск на стоке **MAX 26.33.1** — исправления по репортам юзера:

- 💳 **«Цифровой ID» (доступ через Госуслуги) больше не крашит.** Раньше после переустановки или обновления приложение падало при подключении Цифрового ID — исправлено, вход работает стабильно.
- 🗑️ **Удалённые сообщения больше не возвращаются.** Свои удалённые сообщения (у всех / у себя) после перезапуска приложения теперь остаются удалёнными, как и положено. Анти-удаление чужих сообщений (маркер «удалено» и защита от восстановления) работает как раньше.
- 📞 **Исправлен гудок дозвона на перезапуске активности звонка (MTK/Tecno/Android Go).** Второй путь события «абонент ответил» получил корректную остановку гудка — на устройствах с Android Go гудок не продолжает звучать на фоне разговора.
- 🔔 **«Полноэкранные уведомления» корректно открываются на ColorOS/OxygenOS/realmeUI.** Пункт в «Устранении проблем» теперь ведёт в правильные системные настройки на этих прошивках.

## Продолжаются закрытые угрозы супераппа (из V1/V2)

Каналы утечек по статье **arXiv:2609.11814 «Don't Trust the Super-App»** перепроверены и остаются закрытыми:

- 🔒 **WebRTC: публичный IP не раскрывается** (srflx-кандидат удаляется).
- 📍 **EXIF-GPS: геотеги фото и видео обнуляются** перед отправкой.
- 🚫 **WebRTC debug-dump отключён; FCP-метрика мини-аппов подавлена.**
- 🔐 **Хранилище мини-аппов заблокировано** (мосты DeviceStorage/SecureStorage возвращают null) — push-токены и ключи ESIA не пересекают мост.
- 🌐 **Телеметрия сети заглушена** — параметры оператора, IP и типа подключения не уходят на серверы.

## Известные ограничения

- E2E-шифрование аудио в звонках деактивировано на этом стоке (обфускация call-SDK, безопасный режим) — шифрование сообщений работает как раньше.
- В редких случаях уведомления в фоне могут приходить с задержкой (ограничение прошивок HyperOS на принудительную остановку приложения).
