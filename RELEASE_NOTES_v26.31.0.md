# MAX Mod 26.31.0 RS V10

**Дата:** 2026-09-20 | **Тег:** v26.31.0.10

## Изменения

- **Фикс диалога «Обновите приложение»** (второй, независимый от исправленного в V7 путь): часть пользователей видела системный диалог с кнопками «Обновить и перезапустить»/«В другой раз» — это оказался второй встроенный self-update механизм через HMS AppGallery UpdateSDK, отдельный от уже пофикшенного RuStore-пути. Точка входа (`kw.a(Activity)`) отключена.
- **Скрыт пункт «Поделиться логами»** в настройках мода — известная гонка с ленивой инициализацией стокового провайдера логов иногда выдавала ошибку «Не удалось запустить сбор логов». Пока убран из меню, вернём в будущей версии с более надёжным фиксом.

## Верификация

- Статически: единственная строка версии `26.31.0.10` в classes.dex.
- На устройстве (Redmi): main и клон установлены поверх V9, запущены без крашей/ANR/VerifyError, оба процесса живы.
- Не проверено: подавление самого диалога HMS (нет HMS Core на тестовых устройствах) — уверенность основана на статическом анализе полной цепочки вызова.
