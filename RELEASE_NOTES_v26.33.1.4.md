# MAX Mod v26.33.1.4 — Release Notes

**Дата:** 2026-10-02

## Что нового

Четвёртый выпуск на стоке **MAX 26.33.1** — исправление по репорту юзера:

- 🗑️ **Исправлена ложная пометка «удалено» у обычных сообщений при включённом анти-удалении.** Ранее при antiDelete=ON входящие и канальные сообщения могли сразу получать метку «удалено». Причина: общий FCM-обработчик заносил любой приходящий `msgid` в список «защищённых удалённых», не проверяя тип уведомления. Теперь это делается только для настоящих уведомлений об удалении (`MessageRemoved` / `ChatMessageRemoved`), а канальные публикации больше не помечаются ошибочно. Анти-удаление чужих сообщений работает как раньше.

## Продолжаются закрытые угрозы супераппа (из V1–V3)

Каналы утечек по статье **arXiv:2609.11814 «Don't Trust the Super-App»** перепроверены и остаются закрытыми:

- 🔒 **WebRTC: публичный IP не раскрывается** (srflx-кандидат удаляется).
- 📍 **EXIF-GPS: геотеги фото и видео обнуляются** перед отправкой.
- 🚫 **WebRTC debug-dump отключён; FCP-метрика мини-аппов подавлена.**
- 🔐 **Хранилище мини-аппов заблокировано** (мосты DeviceStorage/SecureStorage возвращают null) — push-токены и ключи ESIA не пересекают мост.
- 🌐 **Телеметрия сети заглушена** — параметры оператора, IP и типа подключения не уходят на серверы.

## Известные ограничения

- E2E-шифрование аудио в звонках деактивировано на этом стоке (обфускация call-SDK, безопасный режим) — шифрование сообщений работает как раньше.
- В редких случаях уведомления в фоне могут приходить с задержкой (ограничение прошивок HyperOS на принудительную остановку приложения).
