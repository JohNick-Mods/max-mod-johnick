# MAX 26.34.0 GP V3 — аудит выпуска

Дата: 06.10.2026  
Run сборки: `c66f15a7b639` (строгий E2E-конвейер, 279 шагов, status=success)  
Предыдущая опубликованная версия: v26.34.0.2

## Итог

V3 — исправления по пользовательским жалобам после V2. Строгая сборка успешна, SHA-256 всех четырёх APK совпадают с `SHA256SUMS`. Независимый верификатор подтвердил дифф патчей, регистры вставок и наличие правок в собранном DEX.

## Изменения и ограничения

- **A11 (краш «Автообновление»):** в патче синхронизации стокового пункта с флагом мода использовалась ссылка `Lhmj;->a`; в 26.34.0 это другой класс без такого поля (NoSuchFieldError при клике). Заменено на актуальный Unit `Lwsj;->a`. Device-verify на Redmi: три переключения подряд, вылетов нет.
- **U7 (окно «Истории, опросы и не только… Скачать»):** серверный информер (`InformerBottomSheet`) теперь подавляется не только для типа SoftUpdate, но и для SelfServiceAuto и любых информеров с кнопкой «Скачать» либо описанием «в новой версии». Тип реального окна по логам устройства не подтверждён; на живых серверных данных не проверено.
- **F14 (реклама в чатах):** баннеры механизма promoted (`promo.banners`) скрываются под тумблером «Скрыть промо-баннеры» (по умолчанию включён). Рекламные посты, пришедшие как обычные сообщения, отличить нельзя.
- **F13 (повторные пуши о прочитанном):** дедупликация уведомлений по msgid теперь действует и при «Умной античиталке»/«Невидимке». Причина установлена по коду, подтверждения логом с устройства нет.
- **C4 (гудок, Redmi 9):** на время гудка громкость медиа поднимается до 70% (если ниже; не при громкой связи и не в беззвучном режиме) и возвращается при остановке гудка, если её не меняли вручную. Не проверено на устройстве с жалобой.
- На экране «О приложении» суффикс версии `V3`.

## Проверка сборки

- Строгая сборка: run `c66f15a7b639`, status=success; 4 APK, ABI/DEX-контракты/подписи проверены.
- Redmi (arm64): main и clone установлены, SHA-256 установленного APK совпадает со сборкой, запуск без вылетов, переключатель «Автообновление» проверен.
- Независимая верификация: дифф против pristine только по описанным вставкам; регистры `e09.a`, `cxe.f`, `i0.n` безопасны; метки без дублей; в собранном DEX нет `Lhmj;->a`.
- Threat-scan: 0 непротриаженных HIGH. Fan-out аудит всех патчей для V3 не проводился по решению владельца; аудит ограничен статическими проверками изменённых точек.

## Известные ограничения

- После сброса E2E нет тихого фонового восстановления сессии; E2E звонков модом не реализовано.
- Некоторые необязательные R8-цели отсутствуют в текущем стоке и пропускаются; точный список — в build report.
- Подъём громкости гудка вызывается только при старте гудка; при ручной смене громкости во время гудка прежнее значение не восстанавливается.

### Открытые, частичные и непроверенные угрозы

- NFC HCE и placeholder разрешения `REQUEST_INSTALL_PACKAGES` в ForceUpdate.
- Отпечатки `du0/wt5`, VPN-потребители `km4/ssb`, фоновый ключ/сокет `keep-background-socket`.
- Остальные потребители `connection_type`; список сетевых endpoint’ов не исчерпывающий.
- Runtime/sentinel-подтверждение отдельных мер DPS/TraceFlow, VPN labels, installer-source spoof и PMS blacklist gate неполное.
- MAX сохраняет прочие SDK, отправители, сетевые пути и серверную обработку данных; аудит локальных патчей не доказывает отсутствие иных сборщиков или обходов.
