# MAX Mod v26.34.0.1 — Release Notes

**Дата:** 2026-10-04  
**База:** MAX 26.34.0 GP  
**Сборка:** `b43e04f51991` (`--strict --e2e`)

## Исправления и проверка

- **E2E в карточке контакта:** исправлены R8-сигнатуры и типы модели в helper настроек контакта; меню не теряет строки при изменении обфускации.
- **Строгий E2E fail-closed:** закрыты пути, где незашифрованный исходный текст мог пройти при ошибке сопоставления peer, REKEY/версии, crypto или повторной записи исходящего сообщения. Control-only префиксы удаляются до обычной отправки.
- **Передача владения:** подтверждён путь установки владельца на устройстве в Strict mode.
- **Баннер штатного обновления:** скрыт pinbar «Обновите приложение» от стока.
- APK включают `libsignal_jni.so` для arm64 и arm7.

Полная сборка прошла: 275 шагов; `pytest tests -q`: 208 passed, 5 skipped. Все четыре APK независимо сверены с `SHA256SUMS`; подписи APK v2/v3 проверены. Smoke на устройстве подтвердил запуск main/clone arm64, без записей AndroidRuntime crash в проверенном запуске.
