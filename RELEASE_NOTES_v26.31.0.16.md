# MAX Mod v26.31.0.16 — Release Notes

**Дата:** 2026-09-25

## Что нового

- 🔄 **UpdateChecker — доработка проверки обновлений:** сортировка тегов релизов по убыванию (раньше при нестандартном порядке тегов могла подхватываться не самая новая версия), исправлен разбор имени файла в HTML-fallback, добавлен резервный путь `mode=14` + `downloadAndInstall`, устранена повторная установка уже установленного обновления (идемпотентность).
- 🛠️ Внутренняя доработка инструментов сборки (r8 hot-override и drift-скан) — не влияет на поведение приложения, ускоряет адаптацию мода к новым сборкам стока.

Функционал приватности и все тумблеры — без изменений с V15 (полный список см. в README).

## Известные ограничения (без изменений с V5)

- E2E-шифрование аудио в звонках перенесено на 26.32.0 (R8-rebump call-слоя) — звонки идут в обычном незашифрованном режиме без ложной индикации защиты. E2E-шифрование сообщений работает как раньше.
- Chat-PIN: long-press заголовка для управления PIN недоступен в 26.31.0 (UI-хук на 26.32.0). Защита PIN при открытии чата работает; список защищённых чатов управляется через ADB (`maxmod.chatpin.add/remove`).

## Обновление

Ставится поверх любой версии 26.31.0 RS (`install -r`), данные сохраняются.

Полный аудит сборки — `AUDIT_26.31.0_RS_V16.pdf` в этом релизе.
