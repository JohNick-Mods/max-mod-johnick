# MAX Mod v26.24.0

**Версия**: 26.24.0 RS V19 | **Платформы**: arm64, armv7, x86_64, x86

## ⚠️ Важный релиз

**Критическое исправление:** SMS-коды при регистрации и входе **были полностью заблокированы** в предыдущих версиях. В V19 это **полностью решено** — SMS теперь приходят корректно.

## Основные улучшения

- 🔧 **SMS-коды при входе** — раньше вообще не приходили, теперь работают
- ✅ Иконка клона (Orange) теперь отображается правильно (была синяя по ошибке)
- ✅ Все остальные функции стабильны

## Установка

1. Загрузить соответствующий APK для вашей архитектуры (arm64, armv7, x86_64 или x86)
2. `adb install -r MAX_26.24.0_armXX_V19.apk` (или обновить из Google Play / Samsung Galaxy Store)
3. Переустановка над предыдущей версией безопасна

## Поддержка

- Основное приложение (main): `ru.oneme.app` (иконка Blue)
- Клон (параллельная установка): `ru.oneme.ap2` (иконка Orange)
