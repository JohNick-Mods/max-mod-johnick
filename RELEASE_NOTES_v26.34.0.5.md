# MAX Mod v26.34.0.5 — примечания к выпуску

**Дата:** 26.10.2026
**Статус:** выпуск подготовлен к публикации  
**База:** MAX 26.34.0 GP  
**Сборка:** V5, run `a250482518d9`  
**Изменения:** относительно V4; предыдущие улучшения 26.34.0 сохраняются

## Изменения

- **Надёжность запуска:** исправлена JNI-совместимость обхода проверки отпечатка для SMS-входа. Нативная декларация метода сохранена; приложение использует отдельный helper в целевом вызове.
- **Исправление падения контекстного меню:** устранено затирание рабочих регистров при открытии меню реакции на сообщение.
- **Звонки:** добавлена синхронизация остановки гудка дозвона с переключением аудиомаршрута, чтобы избежать гонки между остановкой тона и маршрутизацией звука.
- **Внешний вид сообщений:** добавлена настройка `matchOutgoingBubbleColor` (по умолчанию выключена), позволяющая окрашивать исходящие сообщения как входящие.
- **Верхняя и нижняя панели:** добавлена независимая настройка `transparentBars` (по умолчанию выключена) для прозрачности панели чатов и нижней панели.
- **Сборочные проверки:** устранены ложные срабатывания строгого анализа ссылок на поля и типов; добавлены проверки, выявляющие регрессии этих гейтов.

- Автоматический конвейер сборки завершился успешно: run `a250482518d9`; собраны четыре релизных APK arm64/arm7 для основной и clone-версии, а также x86_64 test APK. Контрольные суммы находятся в `RELEASE/26.34.0_GP_V5/SHA256SUMS`.
