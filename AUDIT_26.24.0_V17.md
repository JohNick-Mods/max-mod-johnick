## 🆕 Что нового в 26.24.0 RS V11–V17

### 1. Исправление открытия файлов/PDF в клоне (`#FILE-1`)

**Симптом**: в клоне (`ru.oneme.ap2`) попытка открыть полученный файл или PDF приводила к `SecurityException` — `FileProvider` использовал захардкоженный authority `ru.oneme.app.provider` вместо authority клона.

**Исправление**: конструктор `pm6.<init>(Context, Lvo8;)` (R8-переименован из `yi6` в 26.24.0) теперь строит authority динамически через `getPackageName() + ".provider"`. В основном пакете поведение не меняется (`ru.oneme.app.provider`), в клоне возвращается корректный `ru.oneme.ap2.provider`.

### 2. Расширение нейтрализации серверных PMS-флагов (`#PMS`)

Ранее форсировались 2 ключа (`net-ssl-session-validate` → TRUE, `net-client-dns-enabled` → FALSE). Добавлено ещё 6:

| Ключ | Принудительное значение | Назначение |
|---|---|---|
| `mytracker-enabled` | FALSE | блокировка инициализации myTracker |
| `user-debug-report` | FALSE | отключение отправки отладочных отчётов |
| `tracer-non-fatal-crashed-enabled` | FALSE | отключение логов нефатальных падений |
| `show-vpn-call-bottomsheet` | FALSE | скрыть плашку «отключите VPN» при звонке |
| `show-vpn-chat-bottomsheet` | FALSE | скрыть плашку «отключите VPN» в чате |
| `show-vpn-snackbar` | FALSE | скрыть snackbar «отключите VPN» |

Чокпоинт (write-side гейт PMS-Map) переякорен под R8-rebump 26.24.0: `vmk → xmk → y4l`.

### 3. Покрытие адаптивных иконок

Добавлен недостающий цвет фона `launcher_bg_blue` (раньше синяя иконка использовала сток-фон вместо генерируемого — визуальная асимметрия с остальными 5 цветами). Мипмап-XML теперь генерируются в 3 плотностных бакета (`mipmap`, `mipmap-anydpi`, `mipmap-anydpi-v26`) вместо только `-v26` — шире покрытие лаунчеров/устройств.

### 4. R8-rebump сопутствующие переякоривания (без изменения поведения)
- FCM-диспетчер P1_4: helper `Li80;->d` → `Lr6k;->e`.

## 📦 Из V8–V10 — сохранено без изменений

### Оптимизация размера APK (V9)
Максимальный DEFLATE (уровень 9): **−17.6%** от размера.

### Исправление непрерывного гудка дозвона (`#USER-2 V29`)
`stop()` перенесён из `fc1.b()` (markActive) в `d25.onCallAccepted()` — точное событие ответа собеседника, атомарный `ToneGenerator`.

### Дедупликация уведомлений при Антиудалении (`#PUSH-2`)
Ring-buffer 500 msgId при `antiRead OR antiDelete` + дроссель `ensureServiceRunning` 30 сек.

### Цвет уведомления = цвет иконки (`#ICON-1`)
Тумблер **`notifMatchIcon`** (default ON). Акцент уведомления в шторке совпадает с цветом активной иконки (6 цветов).

### Больше закреплённых чатов (до 10) (`#PIN-1`)
Тумблер **`unlockPinLimit`** (default OFF). Хелпер `AppFlags.pinLimit(I)I` → `10`.

## 🛡 Профиль приватности

### Невидимка (`invisible`) — мастер-переключатель

| Дочерний флаг | Что делает |
|---|---|
| Антипечатанье (`antiTyping`) | собеседник не видит набор текста |
| Античиталка (`antiRead`) | собеседник не видит отметку «прочитано» |
| Умная античиталка (`smartAntiRead`) | «прочитано» уходит только ПОСЛЕ вашего ответа |
| Антиприсутствие (`antiPresence`) | онлайн / last-seen скрыты |

### Анти-удаление (`antiDelete`) — 4 слоя + офлайн-персист
1. **L3 — Central WS chat-event**. 2. **L4 — Room ORM body-clear**. 3. **V3 persist**. 4. **Маркер 🗑 + время**. 5. **Офлайн-удаления через FCM** восстанавливаются на старте.

## ⚠ Честно: ограничения в 26.24.0 RS V17

- **#PIN-1 — серверный сброс**: сервер MAX может сбросить пины сверх 2 при синхронизации. Тумблер default=OFF.
- **#ICON-1 — share-меню и «О приложении»**: Samsung Sharesheet и экран App Info берут иконку из `applicationInfo` пакета (OEM-ограничение OneUI), а не из активного alias. Домашний экран и шторка уведомлений — корректны.
- **Ringback**: ToneGenerator маршрутизируется через STREAM_VOICE_CALL; на устройствах без активной VoIP-сессии в момент DIALING гудок может быть тихим.
- **AMOLED — покрытие ~95%**: отдельные bottom-sheets могут остаться тёмно-серыми.
- **Диалоги мода — тёмная схема** (фиксированный тёмный фон).
- **Watch-фичи** активны только при `widthPixels < 500`.
- **Тумблер `improveNotifications` скрыт из UI**.
- **Требуется one-time `pm clear ru.oneme.ap2`** после первой установки клона.
- **Минимальная версия Android — 8.0** (API 26).
