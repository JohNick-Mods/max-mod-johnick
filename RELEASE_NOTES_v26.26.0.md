## 🆕 Новые фичи

### Оформление

* 🔴 **Красный шрифт (RedCode)** — красное моноширинное форматирование текста (тумблера нет, работает всегда). Чтобы применить: выделите текст в поле ввода → в меню форматирования выберите **«Красный»**. Меняет `ActionMode`-фрагмент в чате.
* 🖼️ **Установка своих обоев чата** — тумблер + пикер: выбрать любую картинку из галереи, применить как фон. Downsample при больших разрешениях (защита от OOM), сохранение в приватном хранилище.
* 🎨 **AMOLED — дивайдеры чёрные** (opt-in) — новый под-тумблер `amoledDividersBlack`: перекрашивает 25 разделителей в списках в чистый чёрный (для OLED-экранов).
* 🎨 **AMOLED — greenmax-палитра** — порт цветовой схемы из донора GreenMAX (акценты, тултипы).

### Навигация

* 🔧 **Кнопка «Починить»** в настройках мода — вызывает `troubleshoot`: сброс кэша флагов, повторный reload, повторное применение чокпоинтов без переустановки.
* ← **Назад в подменю настроек** (`submenu_back` + `submenu_back_onkey`) — кнопка + аппаратная клавиша Назад корректно возвращают в предыдущий уровень меню, а не закрывают весь диалог.
* 🛡️ **Back-cycle guard** — защита от петли BACK-события в кастомных AlertDialog (`OnKeyListener` пара, не `OnDismissListener`).

### Плавающая кнопка FAB

* **Плавающая кнопка «Настройки мода»** на списке чатов — тумблер `showModFab`, drag-and-drop с сохранением позиции между запусками (sentinel `fab_pos_persist`), защита от рестарта дублей (`attached:Z` guard + dist²-threshold).

### Приватность / нейтрализация телеметрии

* **Расширенная нейтрализация телеметрии** — 4 новых чокпоинта:
   * `p0_telem_push` — трекеры push-событий
   * `p0_telem_onelog` — one-log агрегатор
   * `p0_telem_operator` — оператор-фингерпринт (IP-strip)
   * `p0_telem_dps` — DPS-трекер

## 🔧 Исправлено

* **Умная античиталка** — семантика **consume-on-use**: ответил → следующий read-mark пропускается (для накопленных непрочитанных), после — снова блокируется до следующего ответа. Раньше latch держался всю сессию.
* **Антиудаление** — trash-emoji (🗑️) префикс теперь корректно зависит от тумблера `antiDelete`; при OFF удалённые скрываются полностью (раньше префикс показывался всегда).
* **Скрыть каналы (search chips)** — исправлен хардкод пути `c2/hh3 → c2/qh3`, устранена перезапись анкоров между двумя патчами. Чип «Каналы» скрывается стабильно.
* **AntiRead scroll V2** — soft-skip вместо FATAL при отсутствии V1-sentinel (не роняет сборку).
* **Скриншоты** — реально убран `addFlags(FLAG_SECURE)` в `c3/umc.smali` (раньше меняли только путь без правки).
* **WS/Push watchdog (AlarmManager)** — исправлен `const/high16` (полная 32-битная форма `0x0c000000`) — падение сборки при пересборке; рабочий `cancelUniqueWork` вместо no-op (тумблер теперь реально отключает periodic-worker).
* **`chat_pin`** — убран module-level `open()` при импорте (падало при отсутствии inject-файла).
* **`ringback_v29`** — added existence-check + auto-create директории (не падает при чистой сборке).
* **`orientation_fix` / `f1b_biometric` / `devmenu_crashfix`** — R8-имена актуализированы под 26.26.0.
* **«Починить» кнопка** — атомарный two-part-guard: партиальная установка исключена.
* **`wallpaper_greenmax`** — dynamic search по c2/c3 (устойчиво к перебалансировке DEX).
* **Родительский контроль + TimeLock** — preflight-check зависимости от `f1_app_lock` (падение с внятным сообщением вместо тихого no-op).
* **Скрыть «Архив»** — order-independent version 3: preflight + два шага (поле/clinit/set владеет `gen_appflags` через tumblers.yaml).
* **Устаревшие анкоры / R8-имена (21 патч)** — обновлены на актуальные для 26.26.0; добавлены preflight-check для 8 сигнатур (при следующем bump стока падают с чётким сообщением, а не молча).
* **`updater_fallback`** — mirror URL вынесены в константы модуля (проще править при смене репо).
* **`mod_fab`** — WeakRef race закрыт (try/catch Throwable + null-check).
* **Инфраструктура** — `verify_critical` sentinel обновлён `ad_trash_v1 → ad_trash_adgate_v2`; устранены 8 случаев дубляжа поле/clinit/SharedPref между apply-скриптами и `gen_appflags` (единая точка ответственности).
