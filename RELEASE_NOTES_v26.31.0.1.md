## MAX Mod 26.31.0 RS — V1 (2026-09-14)

Первый релиз на новом стоке **MAX 26.31.0**. Весь пайплайн перенесён на новую версию (полный R8-rebump), функционал прошлых версий сохранён.

### Порт на сток 26.31.0
- Устранены краши старта, рендера Switch, старта клона, экрана звонка и экрана **Настройки → Оформление** — все возникали при сборке на новом стоке (R8-drift классов + расхождение ресурсных id стока и собранного APK).

### E2E-шифрование
- **Только по согласию (opt-in).** Убрано авто-включение E2E при входящем push без действия пользователя и ложные служебные плашки авто-включения. Шифрование включается лишь вручную через настройки чата.
- **Фикс открытого текста при редактировании.** Отредактированное E2E-сообщение больше не уходит незашифрованным.
- **Фикс пересборки сессии на стороне получателя** при сбросе доверия без REKEY-токена (раньше шифровало старой сессией).
- **Плашка при неудачной расшифровке первого сообщения** — вместо молчаливой потери показывается служебное уведомление «сообщение не расшифровано, попросите переслать».
- **Устойчивость к сериям сообщений** — закрыта внутренняя гонка при пересборке E2E-сессии.

### Функциональность
- Реально скрываются: чаты «Коды подтверждения» / «MAX», вкладка-папка «Всё», пункты «Пригласить друзей» / «Войти в Сферум» / «MAX для бизнеса» в Настройках.
- Тумблер **«Прочитать всё»** работает.
- **Невидимка** больше не показывает статус «в сети».
- Восстановлен **гудок дозвона** на исходящих.

### Интерфейс
- Нормальный размер шрифта в диалогах мода; длинный текст диалогов и служебных плашек больше не обрезается в одну строку «…».
- Корректное имя приложения (MAX) и смена цвета иконки.
- Стабильный автоскролл к последнему сообщению при открытии чата.

**Базовый APK:** MAX 26.31.0. Обновление с 26.29.1 — `install -r`, данные сохраняются.
