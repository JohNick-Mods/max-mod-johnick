## MAX Mod 26.31.0 RS — V14 (2026-09-24)

Точечный хотфикс поверх V13: убрана назойливая всплывающая шторка про новую версию приложения. Инфраструктура V13 и более ранних версий не тронута.

### Исправления
- **Убрана всплывающая шторка «Появилась новая версия приложения» поверх списка чатов.** Сервер MAX стал присылать части пользователей отдельное уведомление с кнопкой «Загрузить», всплывающее заново при каждом возврате в приложение. Это не диалог самообновления мода (те уже блокировались раньше) — отдельный, независимый механизм уведомлений. Теперь этот конкретный тип уведомления не показывается, остальные уведомления (акции и т.д.) не затронуты.

### Технические заметки
- Один точечный патч: `apply_v_kill_softupdate_informer.py` — детектирует тип уведомления «SoftUpdate» и переводит его в тот же путь, что и незнакомые клиенту типы (не показывать).
- Fan-out аудит остальных активных патчей не проводился (изолированная точечная правка) — осознанное решение пользователя 2026-09-24, риск принят явно (обычно обязателен перед публикацией по HARD-RULE проекта).
- Device-verified: S25, main + clone установлены и запущены, несколько циклов сворачивания/разворачивания — без крашей. Само уведомление в тестовую сессию сервер не присылал (приходит выборочно) — визуальное подтверждение «шторка больше не появляется» не проводилось, статус патча — static-verified по коду + чистый device-smoke.
