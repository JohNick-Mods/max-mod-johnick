## MAX Mod 26.31.0 RS — V5 (2026-09-18)

Первый публичный релиз после V3: V4 не публиковался. В V5 закрыты критические краши, исправлено антиудаление после перезапуска, прозрачная тема и стабильность фоновых задач; прогнан полный аудит всех патчей сборки.

### Критические исправления
- **Краш «Красный» в форматировании текста (A9).** `IncompatibleClassChangeError` при покраске выделенного текста — устаревший класс спана после R8-rebump (`CodeSpan implements Lu0a;`). Device-verified.
- **Антиудаление после перезапуска (F15, F16).** Сообщение, удалённое собеседником «у всех», больше не пропадает после рестарта: центральный гейт в `c1/qua.smali` (фильтр `deletedKept` + блок диапазонных DELETE) + фикс VerifyError `y0c.b` (mismatch `new-instance`/`invoke-direct` при R8-rebump). Device-verified: удаление → рестарт → сообщение на месте.
- **Мёртвые тачи при прозрачной теме (U8).** Битые style-id в патче темы (попадали в чужие ресурсы) → актуальные из `aapt2 dump` собранного APK. Device-verified.
- **Ошибка чтения настроек при старте (F13).** Принудительная запись `Boolean` в типизированные ключи (`user-debug-report` → Long/enum, `keep-background-socket` → enum) → `SharedPreferencesGetException`. Ключи исключены из принудительной записи.
- **VerifyError KeepAliveWorker (F14).** Сток 26.31.0 переименовал `ListenableWorker→sl9`, `doWork→d()Lrl9;` — шаблон переписан по эталону.
- **Краш QR-сканера (A8).** `QrScannerWidget.v1` — переезд класса `Lus4→Loz4`.

### Новое
- **E2E-звонки: отслеживание переключения камеры (video_toggle).** `CameraManagerImpl` переехал c3→c4 — сигнатура не изменилась; `CallCrypto.setVideoActive` корректно гасит/возвращает замок аудио при включении/выключении видео.
- **Полный fan-out аудит сборки перед релизом:** ~290 `apply_v*.py` по 15 направлениям, критических багов не выявлено.

### Известные ограничения V5
- **E2E-шифрование аудио звонков перенесено на 26.32.0** (R8-rebump call-слоя в 26.31.0). Звонки — обычный незашифрованный режим без ложной индикации защиты; E2E-шифрование сообщений работает как раньше.
- **Chat-PIN long-press UI-хук перенесён на 26.32.0** (в стоке 26.31.0 исчез механизм long-press заголовка). Защита PIN при открытии чата работает; список — через ADB broadcast.

**Базовый APK:** MAX 26.31.0. Обновление с 26.31.0 V1/V3 — `install -r`, данные сохраняются.
