# MAX Mod v26.24.0 V5 (RuStore) — watch-фиксы поверх V4

**Сток:** 26.24.0 (RuStore, RS variant) · **Совместимость:** Android 8.0–16.0 (API 26–36) · arm64-v8a + armeabi-v7a · основной + клон (`ru.oneme.ap2`)

Точечные правки по фидбеку с реального теста на часах (OnePlus Watch 3). **Весь UI-функционал V4 сохранён, безопасность и приватность не менялись. На телефонах поведение V4 — 1-в-1** (кроме нового тумблера «Скрыть Истории», по умолчанию OFF). Ставится через `install -r` поверх любой сборки 26.x — данные сохраняются.

## ⌚ Что нового в V5

- **📵 Скрыт блок «Истории» на часах.** На круглом экране `StoriesAppBarBehavior` (sticky-шапка) налезал на список чатов при скролле. Контейнер `chats_list_stories_group_layout` теперь принудительно `GONE` на устройствах с `widthPixels < 500`. На телефоне управляется новым тумблером: **Настройки мода → Папки и вкладки → «Скрыть Истории»** (по умолчанию OFF).
- **🔤 Компактный нижний бар на часах.** Подписи вкладок («Наст», «кты», «Звонки»…) обрезались на круглом экране. Теперь на часах в нижнем баре (`oneme_main_bottom_bar`) рекурсивно скрываются все текстовые подписи — остаются только иконки. По типу View (`instanceof TextView`), не по R8-имени — устойчиво к следующим бампам стока.
- **🌗 Читаемость меню «Настройки MAX».** Тема диалога настроек выбиралась по системному night-mode, а фон при этом всегда принудительно тёмный (`#2D2D2D`) — при светлой системной теме получался тёмный текст на тёмном фоне. Пункты меню (`setItems`) создаются лениво, после `show()`, и не попадали под пост-тонировку. Теперь тема диалога всегда тёмная — белый текст гарантированно, независимо от системной темы устройства.

## 🐞 Из V4 — сохранено

Bounded ScrollView в диалогах на часах, точечное скрытие верхнего индикатора списка чатов, ABI-фильтр обновлятора, 3 кнопки в диалоге проверки обновления, WearOS wearable-метаданные в манифесте.

## 📱 SMS-регистрация — работает

WS-redirect от сервера MAX (шардинг auth-flow по номеру) не блокируется. SMS-код доходит для новых номеров штатно.

## ⚠ Известные ограничения

- **AMOLED** — покрытие ~95% (список чатов и нижние шторки могут остаться тёмно-серыми).
- **Диалоги мода — тёмная схема** (фон фиксированно тёмный для гарантии контраста).
- **Закруглённые диалоги** — best-effort: у отдельных системных диалогов углы могут остаться прямыми.
- **Watch-фичи (V4+V5)** активны только на устройствах с `widthPixels < 500` (гейт runtime). На телефонах инертны.
