## 🆕 Унаследовано из V11 (без изменений)

### 🤝 Тихий двухраундовый E2E-handshake

Signal Protocol (X3DH + Double Ratchet). Защищённая сессия готова ещё до первого сообщения пользователя. Обмен невидим: не создаёт пузырьков, не порождает push, не течёт в открытые логи.

### 🔐 Сквозное шифрование личных чатов (E2E)

Signal Protocol. Ключи не покидают устройство, сервер видит только шифртекст. Активация — «Начать защищённый чат», обмен pre-key bundle по QR/deeplink, верификация — сверка отпечатка. Каналы и группы не поддерживаются.

### 🔄 Служебная плашка при сбросе E2E-доверия/сессии

Постоянное системное сообщение в истории чата при сбросе доверия или сессии — переживает рестарт приложения.

### 🔑 KEY-RECOVERY

Информативный диалог при обнаружении смены ключа собеседника: что произошло, что делать.

### 🔴 Fail-closed отправка

В строгом режиме шифрования сообщение не уходит открытым текстом при сбое шифрования.

### 🎛️ Глобальный тумблер «E2E Шифрование»

Мастер-переключатель  в разделе «Приват», по умолчанию ВЫКЛЮЧЕН. При ВЫКЛ мод ведёт себя как оригинал; при ВКЛ — работает прежняя per-chat система режимов.

### 🙈 Невидимка (antiRead)

Скрывает статус прочтения и присутствия.

### 📂 Старт на «Новые»

При включении тумблера (Настройки MAX → Чаты) приложение открывается сразу на папке «Новые».

### 🚫 Скрытие мусорных папок, прочих элементов UI

Фильтры папок, скрытие кнопки «Прочитать всё», скрытие пункта «Дизайн система» в dev-меню и прочие UI-настройки.
