# MAX Mod 26.31.0 RS — V12 (21.09.2026)

Хотфикс поверх V11.

## Исправления

- **Крашлуп при работе в фоне** — устранён `StackOverflowError` в фоновом приёмнике будильника (дублирующийся метод с самовызовом), приводивший к периодическому падению и автоперезапуску приложения.
- **Четвёртый self-update путь** — нейтрализован ещё один внутренний механизм автообновления стока (через задачу инициализации аккаунта), в дополнение к уже отключённым RuStore/HMS/ForceUpdateScreen.
- **E2E-шифрование** — версия мода теперь переанонсируется собеседнику и при уже установленной сессии (не только при первом рукопожатии/сбросе) — устраняет ложное «у собеседника старая версия» после обновления мода без сброса переписки.

Перед публикацией прогнан полный fan-out-аудит всех патчей пайплайна (274 скрипта).

Обновление с V11/V10/V9 — `install -r`, данные сохраняются.
