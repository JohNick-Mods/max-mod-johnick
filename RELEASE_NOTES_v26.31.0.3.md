## MAX Mod 26.31.0 RS — V3 (2026-09-16)

Хотфикс-релиз поверх V1 (v26.31.0.1): критический фикс отправки видео, краш QR-сканера, пустой список «Устройства», синхронизация «Автообновления», 8 R8-drift-фиксов аудита.

### Критические исправления
- **Отправка видео (F12).** Видео-вложения не отправлялись (фото работали): устаревшие имена классов в патче `UploadFileAttachWorker.getForegroundInfo` → WorkManager отменял expedited-задачу. Восстановлен стоковый путь загрузки. Device-verified: видео отправляется.
- **Краш «Устройства → Войти по QR-коду» (A8).** VerifyError `QrScannerWidget.v1` — переезд класса `Lus4→Loz4`.
- **Пустой список «Устройства» (F11).** Патч скрытия настроек мис-таргетился на экран устройств; исключён из сборки. Список сессий снова полный.

### Новое
- **Синхронизация «Автообновления».** Стоковый переключатель «Автообновление» (Настройки → О приложении) зеркалит мод-флаг «Автоматически проверять при запуске»; стоковый self-service update (перезаписывающий мод оригиналом) не запускается.

### Аудит перед релизом (R8-drift фиксы)
- Обход клиентского блэклиста расширений файлов активирован на 26.31.0 (c3/dnd → c4/g4e).
- Исправлены якоря: перетаскивание закреплённых, скрытие каналов в поиске, gate телеметрии DPS, no-IP телеметрия.
- Voice-download снова активен (якорь c3/s63.smali).
- Патч скрытия пунктов настроек больше не затирается при пересборке.

**Базовый APK:** MAX 26.31.0. Обновление с 26.31.0 V1/V2 — `install -r`, данные сохраняются.
