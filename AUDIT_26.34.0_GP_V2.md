## Итог

Этот отчёт сопровождает V2 и разделяет комплектность APK и доступность функций. Последняя строгая сборка успешна, SHA-256 всех четырёх APK совпадают с `SHA256SUMS` (независимая сверка).

## Изменения и ограничения

- **F9 (папки чатов):** вернулась полоска «Все / Новые / Личные / Каналы». Причина — патч бейджа «Новые» (F2) затирал живой регистр `v3` в `bj7.updateCounter`; класс не верифицировался, счётчики папок не работали и список папок не обновлялся. Патч переписан на свободные регистры v6/v8/v9; независимая сверка регистров CONFIRMED, device-verify на Redmi (main+clone).

- F12 G1/G2 перенесены на актуальные места `c1/kq3.G/H`; G3 использует существующий FAB-гейт. Статическая проверка DEX подтверждает вызовы `gateRowUnread(Lnh3;)I`; полный интерактивный сценарий бейджа отдельно не подтверждён.
- B6 тихой E2E-отправки отключён: безопасная DI-точка входа не подтверждена. Интерфейс говорит, что новый обмен начинается обычным исходящим сообщением; в строгом режиме без сессии оно блокируется.
- B7 содержит проверки l0a в `dba` до чтения карты декораций для `E2eHolder`.
- A8/A9/A10, F11 и U6 вошли относительно V1: TouchDelegate/detach и диагностика A8; скрытие pinbar обновления; безопасная загрузка настроек; повторное применение share-theme при тёплом `ACTION_SEND`; поиск стилей по имени с защитой от дрейфа resource ID.
- На экране «О приложении» строка версии дополняется суффиксом `V2` в двух местах. Это подтверждение по коду/DEX, не снимок экрана.
- E2E справки исправлены: закрытый ключ остаётся локальным, открытые ключи/prekey-пакеты передаются для сессии; режим чата вручную включается и выключен по умолчанию; тихий обмен после сброса недоступен; `AUDIO` вложения поддерживаются условно; E2E звонков и видео-кружков нет.
