# MAX 26.31.0 RS V15 — Release Notes

Точечное усиление приватности поверх V14 + фикс зависшего баннера обновления.

## 🕵️ Нейтрализация скрытой слежки/аналитики

По результатам комплексного аудита выявлено и закрыто 6 ранее непокрытых путей утечки данных о пользователе:

- **Статистика звонков** — SDK звонков собирал и отправлял на сервер метрики каждого звонка (длительность, качество, тип сети). Сбор отключён, сам звонок не затронут.
- **VPN-признак в аналитике** — три независимых места передавали серверу признак использования VPN (в аналитике звонков, метке типа сети, общем метрическом лейбле). Все три теперь принудительно сообщают «не VPN».
- **Серверный URL восстановления аккаунта** — сервер больше не может задать произвольный адрес для флоу восстановления сессии.
- **Метрики сторонних SDK** — фоновый сбор метрик RuStore и отчёты HMS-аналитики нейтрализованы. Push-уведомления не затронуты.
- **Диагностика Tracer SDK** — закрыт ещё один, ранее не покрытый путь отправки диагностических данных устройства (defence-in-depth).
- **🆕 Новый тумблер «Блокировать запрос телефона мини-приложениями»** (Приват → Данные и профиль, по умолчанию **включён**) — мини-приложения (боты) больше не могут молча получить номер телефона пользователя без его подтверждения.

## 🔄 Исправлен баннер «Доступно обновление», который не гас после установки

После обновления до V14 экран «О приложении → Обновления» продолжал показывать «Доступна v26.31.0.14», даже когда она уже была установлена (и через мод, и вручную с форума). Причина — внутренняя метка версии сборки не была поднята при сборке V14. В V15 исправлено.

## ⚠️ Отступление от процедуры

Полный fan-out-аудит всех патчей пайплайна для V15 не проводился (как и для V13/V14) — новые изменения изолированы в независимых новых скриптах и не пересекаются с общим кодом, кроме точечного расширения уже проверенного PMS-гейта. Подробности и принятый риск — в AUDIT_26.31.0_RS_V15.md.

Полный технический разбор — в приложенном `AUDIT_26.31.0_RS_V15.pdf`.
